# demo/videos/ — подготовленные DEMO-ролики (COMMON-папка)

Сюда кладутся короткие видео (~10 секунд) для демо-сценариив.
Воспроизводятся как есть — **без реального ускорения**;
«ускоренное демо-время» показывает только таймер интерфейса.

## Ожидаемые файлы

| Сценарий | Файл | Что происходит в кадре |
|---|---|---|
| `normal` | **normal.mp4** | Линия движется, рабочий в ROI — штатная работа |
| `stopped` | **stopped.mp4** | Линия остановилась, рабочий на месте (наладка/обслуживание) |
| `person_left` | **person_left.mp4** | Линия движется, рабочий уходит из ROI |
| `stopped_no_person` | **downtime.mp4** | Главный сценарий: линия остановлена + рабочий ушёл → ПРОСТОЙ |

## Требования к файлам

- формат: **MP4** (H.264), длительность ~10 секунд;
- разрешение: любое, рекомендуется 1280×720;
- имена — строго как в таблице (их же ждёт `app/video/demo.py`);
- отсутствующие ролики не ломают систему: DEMO-источник сообщит,
  какого файла не хватает.

Как только ролики добавлены — сообщите Lev, будет выполнена подключка и проверка.
